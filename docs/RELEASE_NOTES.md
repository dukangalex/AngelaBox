更新说明（测试版）
• 本版是 **测试内核**，不是稳定版。日常使用请留在 1.0.57。安装本包后，稳定通道不会再提示降回 1.0.57；要回稳定版请到 GitHub 下载 1.0.57 覆盖安装（签名相同）。
• 内核已对齐官方 sing-box **v1.15.0-alpha.5**（Go 1.25.5，fork tag `v1.15.0-chain.1`，commit `5e1593f0`）。链式出站保留。不跟 1.14.1（Go 1.26.8）。
• 新内核使用 sing-tun 自有 TCP/IP 栈（峰值性能、能耗、内存优于旧实现）。配置里的 TUN `stack` 会静默去掉；仪表不会因此显示「已修正」。
• 官方新增 Tailcat 入站/出站（Tailscale 数据面、无控制面）。现有配置不用改即可用。
• 应用内更新在 1.0.57 已改为解析 APK 签名块。本测试包是 GitHub 预发布：设置 → 应用 → 更新通道选「测试版」后，检查更新才能看到。也可直接从本页安装。
• 发行证书仍为 CN=ChainBox（SHA-256 `e7041217…`），未轮换。订阅 / 脚本 / 更新 / WebDAV 仅允许公网 HTTPS。
