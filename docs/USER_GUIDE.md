# AngelaBox 使用说明

AngelaBox 是面向社区用户的 Android 代理客户端，基于开源 sing-box 内核。界面与设置只描述功能本身，不绑定任何机场或订阅商。

**基准：注重隐私、安全防护、高能低耗、开箱即用。** 不上传、不记录、不缓存日志；启动失败会中文说明并回滚；配置规范化只在真正改写配置时提示，没有错误不显示横幅。中国直连 / DNS 防泄漏 / 广告拦截 / 严格路由 / 禁用 IPv6 / 禁用 QUIC（放行国内）默认打开（脚本单独开）。子页面可下拉返回上级，日志/工具/设置下拉回主页。只要节点本身可用，配置格式由 App 自动适配当前版本。测速完成后节点按延迟从低到高排列。

## 安装

1. 从项目 Releases 下载 **AngelaBox-android.apk**。同目录的 `AngelaBox-android.apk.sha256` 可用于校验；应用内更新必须校验 SHA-256 和发行证书。不要从 `goodmen001/AngelaBox` 或其他来路安装。
2. 允许安装未知来源应用后安装。
3. 同一签名且 versionCode 更大的新版可直接覆盖。**v0.1.x 是调试签名，不能覆盖安装 1.0.x，必须先卸载。**

Windows 图形客户端见同一次 Release 的 **`AngelaBox-v*-windows-amd64.zip`**（解压运行 `AngelaBox.exe`），用法见 [WINDOWS.md](WINDOWS.md)。无版本号的 `AngelaBox-windows-amd64.zip` 是命令行，不是图形界面。Android 与 Windows 不要混用安装包。

设置 → 应用版本 应与 Release tag 一致。快捷设置磁贴名称与图标为 AngelaBox 立方体；覆盖安装后若仍显示旧名或旧图标，长按磁贴移除后再添加一次。

语言可在 **设置 → 应用 → 语言** 中选择简体中文、繁体中文、English 等。

外观可在 **设置 → 主题** 中选择自动 / 浅色 / 深色、主题色彩，以及深色下的纯黑模式。

检查更新：打开 **设置 → 应用 → 检查更新**。有新版本会弹出「下载安装 / 查看发布」。请先允许安装未知应用。默认会打开系统安装界面确认后再覆盖；覆盖安装完成后会自动回到 App。若开启了「静默安装」且环境允许，才会跳过确认界面。默认只提示稳定版。要装 1.15 测试内核，请把 **设置 → 应用 → 更新通道** 改为「测试版」，或从 GitHub Releases 安装标记为 Pre-release 的包。

服务以前台服务和 `START_STICKY` 方式运行。设置 → 服务 里若提示后台权限，点允许忽略电池优化：仅在用户明确授权后，息屏时才保持隧道与当前节点；未授权时应用会在 Doze 暂停内核，并在设备唤醒后恢复，避免无意义耗电。自动选择约 10 分钟测一次，并靠 TCP keepalive 维持会话，避免每分钟唤醒无线电和持续占用内存。国内厂商（小米 / 华为 / OPPO / vivo）还要在系统设置里允许自启动与后台运行，见 dontkillmyapp.com。Windows 图形端以系统服务常驻，不涉及这项。

## 导入配置

1. 仪表 → 添加配置。
2. 导入订阅或本地 JSON，设为当前配置。
3. 如需跨配置串联，再导入另一份落地配置。落地不必设为当前配置。

远程订阅只允许 HTTPS。已保存的 HTTP 订阅更新时会被拒绝，请改成 HTTPS 后再更新。脚本导入同样只允许 HTTPS。

远程订阅若含 Clash 风格 `plugin_opts` 对象，或仍使用 sing-box 1.11 的 `dns.fakeip` / `servers[].address` / `rcode://` / `type: rcode`，或入站仍写 `sniff` / `domain_strategy`、出站仍用 `type: dns` / `type: block`，导入和启动时会自动转成 1.12+ 的 typed DNS 与路由动作，避免内核拒绝。GitHub `raw.githubusercontent.com` 规则集地址会改写到 jsDelivr testingcf 镜像，避免 raw/LFS 404 导致无法启动。

## 链式代理

Chain 是 sing-box 原生 outbound：按你指定的顺序串联已有出站。不绑定机场或协议。

**每份配置独立绑定。** 在某一份配置上保存的链路不会套到其他配置；切换后各自走自己的落地。链式页用入口 / 落地两个节点表示当前链路，下方「已有 N 个链式代理配置，点此查看」可看到其他配置落到哪里。仪表是中枢：顶部 **配置**（全部配置，点开后用右上角 + 添加）和 **更新当前配置**，模式芯片切换 Rule/Global/Direct。点 **入口/出口/节点** 打开分组，点速率或折线图打开连接，点运行中/内存/动态路径图打开日志，点链式芯片或右上角箭头打开链式页。底栏仍是 仪表 / 日志 / 工具 / 设置。子页面可下拉返回上级，从日志/工具/设置下拉回仪表。右侧图标用于启动或停止服务。链式时「出口」始终是落地**节点**，前置分组当前选中的节点只出现在「入口」。下方是最多四列的放射状实时路径。直连走下半条灰色路径，代理走上半条彩色发光路径。点击延迟可对当前节点测速。

**订阅更新不会清掉链式。** 入口/落地存在本地设置里，不写进订阅 JSON。远程刷新只换节点列表，启动时再按绑定组链。若入口分组被改名，会自动改用当前配置的主分组，落地仍有效。

1. 把要串联的配置设为当前配置。
2. 打开 **工具 → 链式代理**。页面说明都在右上角 ⓘ：非中国流量必须经落地出口；链式与脚本可同时开启：脚本先处理当前前置订阅，再由 Chain 把前置连到落地。顶部下拉可选任意配置，不必先切成当前配置。点中间两个节点分别选入口和落地。下拉页面可返回；房子按钮回仪表。
3. **选择入口**：当前配置里的分组或节点（前置）。不要依赖「漏网之鱼」。前置只作为链式第一跳，不会单独成为出口。
4. **选择落地**：当前配置里的另一个节点，或另一份配置里的分组/节点。
5. 点 **确定并保存**，会回到仪表。
6. 若服务已在运行会自动重载。链路为：入口 → 落地 → 目标。IP 检测应显示**落地**地址。

**Fail Closed**：链路或节点失败会明确报错并停止启动，不会偷偷改走 DIRECT。指向入口的**路由规则**会改写到 Chain，避免入口 IP 泄漏。链式模式下**非中国流量不可直连**，必须经链式代理后从落地节点出口；中国直连开关仍可让国内与局域网走 DIRECT。DNS `detour` **不改写**，解析仍走原来的一跳出站（与 Clash Meta 相同），同配置链式不会因此多一跳。

跨协议且两端都启用 TLS 的组合（例如 VLESS 经 Trojan、VMess 经 VMess）在官方 sing-box 上存在已知限制（[SagerNet/sing-box#3205](https://github.com/SagerNet/sing-box/issues/3205)，官方不计划修复）。更稳妥的是入口或落地一侧使用 SOCKS / HTTP / SSH。AngelaBox 的链式出站建立在官方 `detour` 语义上，应用层无法绕过该限制。若链路连不通且测速显示落地正常，优先怀疑这一组合，而不是落地节点本身。

**取消链式**：只取消当前配置；其他配置的绑定保留。删除配置时会清掉相关绑定。

## 配置覆盖

路径：**设置 → 配置覆盖**。开关只改运行时，不改订阅文件。**开启后强制覆盖对应字段**。除脚本外，下列开关默认全开（已安装用户首次升级也会打开一次）。点 ⓘ 可看说明。

**和脚本的关系：** 同一配置任何时候只跑一套规则。脚本开着时，这些开关传给脚本（`overlay`），由脚本写入对应功能；应用不会再叠一套。关掉某一项，脚本里的对应规则就不写。关掉脚本后，由应用自己写入。默认全开，不必去改脚本代码。

| 开关 | 作用 |
|------|------|
| 配置规范化 | 只在配置本身有内核无法识别的写法时才改写，并提示「已修正」及具体条目。没有错误不显示横幅，也不改分流。节点、分组、分流保留；无效规则集换成官方地址而不是丢掉。修正不会关闭该配置上的脚本；链式不受影响。默认开 |
| 防 WebRTC 泄露 | 在中国直连等绕过规则之前拒绝 STUN/TURN（UDP 3478-3481/5349/19302-19310、TCP 3478/5349、主机名含 stun./turn.）。国内 STUN 同样拦截 |
| 广告拦截 | 注入官方 geosite-category-ads-all 规则集并拒绝匹配流量。不改订阅文件，国内广告同样拦截 |
| 中国直连 | 打包绕过：中国 IP/域名（含 IPv6）、中国公共 DNS IP/域名、局域网 IP/域名。只改路由，不注入 DNS 服务器（避免内核因空 direct detour 无法启动） |
| 严格路由 | 强制 TUN `strict_route` |
| 按需连接 | 1.15：空闲时断开 WireGuard / Tailscale / OpenVPN / OpenConnect。默认开。不是分流，脚本开着时应用仍写入 |
| 自动重定向 | 需要 ROOT；1.15 起支持热点/中继转发。默认关 |
| DNS 防泄漏倾向 | 强制 DNS 独立缓存、自动探测网卡 |
| 禁用 IPv6 | 强制 DNS `ipv4_only`，拦截 IPv6。关闭后走 IPv4/IPv6 双栈 |
| 禁用 QUIC | 拦截 UDP 443 |
| 排除国内 QUIC | 国内域名 UDP 443 走 direct，其余仍拦 |

官方 sing-box 客户端并不对订阅节点自带的 ECH 做额外处理。AngelaBox 同样不提供 ECH 开关，节点里若写了 `tls.ech` 会原样交给内核，不会改写也不会强开。

内核日志等级默认 **info**。

## 分应用代理

路径：**设置 → 分应用代理**。

扫描按**网络用途**判定，不是按品牌或「非中国 = 其余全部」：

- **中国应用**：面向中国网络，不依赖代理即可使用（微信、支付宝、国内银行等）。
- **非中国应用**：在中国网络下需要海外路径（Google、Telegram、YouTube、Play 商店等）。
- **系统组件、厂商框架、其他 VPN/代理客户端**：不自动勾选。不确定的应用也不猜。误把系统应用推进名单会导致无法联网。

白名单：扫描「非中国应用」后点应用，只有勾选的走代理，其余直连。
黑名单：扫描「中国应用」后点应用，勾选的直连，其余走代理。

仍可手工勾选或取消。扫描不准时请不要全选系统应用。

## 覆写脚本

路径：**工具 → 脚本**。卡片里下拉选配置，再开关。打开后只跑脚本这一套：国内直连、国外代理，不改订阅。YouTube / Gemini 走代理（国外 QUIC 会先拦再走 TCP），国内 IP/域名（含 IPv6）直连。链式开启时**前置订阅的脚本仍然会跑**（先改分组/分流，再入口→落地组链）；落地配置上的脚本不会套到当前配置。下拉页面可返回；房子按钮回仪表。

链式开启后**前置订阅的脚本仍然生效**，顺序是：脚本改分组和分流 → 链式把入口接到落地。落地配置上的脚本不会套到当前配置。默认脚本对齐原版机场覆写：**国内 IP/域名先直连**，国外域名走代理，国外 DNS 经节点解析。系统 DNS 会先劫持；国外 QUIC/HTTP3 拦截后回落 TCP，YouTube / Gemini / AI Studio 才能打开。🔰 节点选择 / ♻️ 自动选择 / 广告拦截 / 远控工具在前，地区组在最后。广告拦截与远控可在 REJECT-DROP、REJECT、DIRECT（远控还有国外服务）之间切换；节点选择不提供 DIRECT。叶节点会去掉 detour / dialer-proxy，避免订阅把链式带进来。内核没有独立拦截出站，广告与远控在本机黑洞上实现。规则集只用镜像上存在的文件。若本机仍保存着旧版默认脚本，启动和打开脚本列表时会自动换成当前版本。启动时会把会 404 的远程规则集换成官方地址（保留原来的名字），并剥掉直连出站上已删除的覆写字段，避免无法启动。脚本编辑为全屏页。

隐私防护、广告拦截、中国直连、网络增强都写在默认脚本里，默认全开。开或关请用 **设置 → 配置覆盖** 的对应开关，不必改脚本代码。脚本开着时应用不再重复写入这些规则，避免两套冲突。

从 Releases 下载的 APK 附带 SHA-256 校验文件。频道消息里的 SHA-256 是同一串十六进制，用来核对安装包是否完整、是否被改过；不是密码，也不需要手动输入才能安装。应用包名保持 `io.chainbox.app`，覆盖安装时才会替换同一应用。

## 备份

**设置 → 备份与恢复**。

WebDAV 走 HTTPS，并按当前分流规则走内核路由：海外网盘走代理，国内网盘可直连。连通性指示灯常驻自动检测，检测方法与实际上传相同（HEAD/GET），绿灯表示可访问，红灯表示认证或网络失败。部分网盘需要单独的应用密码。

备份文件不含 WebDAV 密码与更新令牌。当前版本写出可移植格式（`angelabox-cloud/1`），同一 WebDAV 帐号、同一个 `backup.zip`，以后可在 Windows 图形端恢复；反之亦然。旧备份仍可在本机 Android 覆盖/兼容恢复。

恢复分覆盖 / 兼容两种策略。**覆盖**用备份完全替换当前配置、设置和订阅文件；**兼容**把备份里的配置追加进来，与现有数据共存，不覆盖已有配置和设置。覆盖会先停服务。下载内容会校验 ZIP 文件头。备份不含账号密码，覆盖后仍保留本机 WebDAV 密码。

## 调试

**工具**页：链式代理 / 脚本 / 网络质量 / STUN / 崩溃报告。

开启防 WebRTC 后，STUN 测试失败是预期（端口被拦）。测 NAT 时请临时关掉该开关。

分享崩溃报告时可选择不包含配置与日志，避免节点地址与凭证外泄。

## 常见问题

**必须卸载才能装新版**  
debug 与正式签名混过。卸载后装正式 `AngelaBox-android.apk`，以后同一 keystore 可覆盖。

**链式连上了但比 Clash Meta 慢很多**  
旧版会把 DNS detour 改写到整条 Chain（DNS 多走一跳），并克隆 urltest 分组导致双重测速。当前版本 DNS 保持一跳，同配置分组就地过滤。请用当前发行版重载。

**仪表链路图不像流量图**  
请更新到当前发行版。链路图按来源、规则、当前入口/落地和目的站绘制放射状路径，有流量时缎带会流动。

**链式保存后无法启动**  
请更新到当前发行版，并在链式页手动选择代理分组（不要用「漏网之鱼」）。

**链式连上了但 IP 是前置**  
保存链式后重载。出口 IP 应始终是落地。前置只作为第一跳。

**保存链式后所有配置都变成同一条链路**  
为每个配置分别保存。取消当前配置不会清掉其他配置的绑定。

**订阅一更新链式就没了**  
绑定存在本地，刷新后自动组链。若入口分组改名，会回退到主分组。

**WebDAV 连通失败，但备份又能成功**  
旧版用了 Android 不支持的 PROPFIND，误报失败。当前版本连通检测与备份使用同一接口。

**WebDAV 证书校验失败 / 国外网盘连不上**  
旧版备份会尽量绕过 VPN 走系统直连，海外网盘在国内链路下容易拿到错误证书。当前版本 WebDAV 按分流走内核路由，海外站点走代理。请用当前发行版重试。

**能备份但不能恢复**  
可在恢复策略里切「兼容」（与现有配置共存）。请用当前版本重新备份后再恢复。

**切换配置后通知栏还是旧名字 / 要停再开才生效**  
旧版切换只改了界面选中项。当前版本在服务运行时切换配置会自动重载，通知栏标题与内核会跟上新配置。

**兼容恢复把现有配置盖掉了**  
旧版「兼容」只是跳过损坏条目，仍整库写回。当前版本：兼容 = 备份与现有共存；覆盖 = 备份完全替换现有。

**导入报 unknown transport type: rcode / legacy DNS fakeip / legacy inbound fields**  
订阅仍用 1.11 写法。当前版本导入和启动时会自动迁移：`dns.fakeip` → `type: fakeip`，`rcode://` 与 `type: rcode` → DNS 规则 `action: predefined`，入站 `sniff` / `domain_strategy` → 路由动作，`type: dns` / `type: block` 出站 → `hijack-dns` / `reject`。请用当前发行版重新导入或直接启动（启动时也会迁移）。官方客户端同样会拒绝这些字段。

**开启脚本后国内走香港 / YouTube、Gemini 打不开**  
旧脚本把国外规则写在国内 IP 前面，国外 DNS 又直连 8.8.8.8，在国内会失败。当前默认脚本：国内 IP/域名先直连，YouTube / Gemini / AI Studio 走代理，国外 DNS 经节点解析。打开脚本页会自动换成最新默认脚本，然后重载即可。

**启动报 outbound detour not found: proxy-select / 规则集下载失败**  
脚本改写了分组名字，订阅里的规则集下载仍指向旧出站。当前版本会按官方 1.14 写入无 detour 的 `http_clients`，国内镜像直连下载。若仍失败，应用会关掉脚本重试并弹出中文说明。修好脚本或在该配置上关闭脚本即可。

**开启脚本后和中国直连/广告拦截打架**  
同一配置同时只能跑一套规则。脚本开着时，配置覆盖开关控制脚本里的对应功能，应用不再额外写入。关掉脚本后这些开关由应用自己生效。配置规范化只在真正改写配置时提示「已修正」；没有错误不显示横幅。链式会在脚本之后组链，二者可以同时开。规范化不影响链式。

**新增配置变成了当前配置**  
当前版本只有还没有任何当前配置时才会自动选中新建/导入的配置。已有当前配置时，新配置只加入列表，需要你再点选。

**启动报 rule-set HTTP 404（geoip-cn / geosite-cn / telegram.srs 等）**  
订阅把规则集指到 `raw.githubusercontent.com`，或用了镜像上不存在的短文件名（例如 `telegram.srs` 而不是 `geosite-telegram.srs`）。当前版本会改写到 jsDelivr testingcf 镜像，并把无效文件换成官方 sing-geosite / sing-geoip，原来的名字保留，APP 分流还能对上。重新导入或重载即可。

**检查更新闪退 / 崩溃报告写「请先允许安装未知应用」**  
旧版把权限提示当成未捕获异常。当前版本会打开系统「安装未知应用」页并提示，不会崩溃。允许后请再点一次更新，应出现系统安装界面。

**恢复备份后闪退 settings.db already-closed**  
旧版关闭 Room 后仍用已关闭的实例。当前版本会在恢复后重新打开数据库，并继续热重启 App。

**WebRTC 测出国内 STUN 泄露真实 IP**  
旧版把中国直连规则写在 STUN 拦截前面，bilibili/小米等国内 STUN 被直连放行。当前版本会先拒绝 STUN/TURN。请打开「配置覆盖 → 防 WebRTC 泄露」后重载。

**检查更新报 HTTP 403 / AuthenticationFailed**  
旧版把 GitHub 发行包的 Azure 下载签名二次编码了，校验和文件拉不下来。请用浏览器打开发布页安装 1.0.55 或更新版本，之后应用内检查更新即可。当前页的「查看发布」也会打开同一地址。

**检查更新报「安装包没有签名证书」或英文 APK has no signing certificate**  
1.0.56 用系统 PackageManager 读未安装 APK 的签名，三星 One UI 等机型经常读空，但安装包本身是签过名的，系统安装器可以装。请点「查看发布」安装 1.0.57；该版本改为直接解析 APK 签名块，之后即可继续用应用内更新。

**检查更新没反应**  
若系统拦截未知来源，会先跳到「允许安装未知应用」。也可点「查看发布」用浏览器下载。默认安装会弹出系统安装界面，不会静默覆盖。默认通道只提示稳定版；1.15 测试内核在 GitHub 预发布，需把更新通道改为「测试版」或从 Releases 安装 Pre-release。

**启动后内核报 TUN stack deprecated / unknown field stack**  
1.15 起请去掉 TUN 的 `stack`。当前版本会在导入/启动时静默删除该字段，不必改订阅原文。

**分组里看不出当前走哪个节点**  
打开「组」：每个策略组标题下会写当前选中的节点，已测速的带延迟。灰色圆点是还没测速，不是掉线；点测速图标即可。

**设置 → 核心 显示 unknown**  
1.0.57 与 1.0.58-beta 发版时浅克隆没有 git tag，内核 `Libbox.version()` 会变成 unknown。请安装 1.0.59-beta 或更新：编译前会打上发版钉死的内核 tag，界面用该 tag 兜底。1.0.62-beta 显示 `1.15.0-chain.2（官方 1.15.0-alpha.6）`。点「销毁」清空工作目录后，「数据大小」为 0 kB 是正常的。
