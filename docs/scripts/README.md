# 可选覆写脚本

应用不内置机场覆写。以前导入并留在本机的「机场覆写」，打开脚本列表时会删掉。全地区分组已经是默认脚本，不要再导入一份绑到同一配置上。链式开启时，配置上的脚本仍然会跑（先脚本，再组链）。

内置默认脚本是 `app/src/main/assets/scripts/airport-region.js`（`overlay-revision: 27`）。它按全地区识别分组。地区自动选择是地区选择组里的一个成员，分组列表不单独再列一张卡片。没有负载均衡 / 故障转移。延迟挑选用 urltest，手选用 selector。设置里的配置覆盖开关作用在这份脚本上。不要再把同一份逻辑当成第二个脚本绑到同一配置。

识别规则（27 起）：每个节点只归一个地区，按「国旗 → 中文名 → 英文名 → 大写代码」逐层找，同一层取最靠左的，同一位置取最长的（罗马尼亚不会落进意大利，马里兰归美国）。英文名和代码先把名字拆开（`HK01`、`HK_01`、`HongKong` 都能认），只认整词；两字母代码只用白名单（`SS`、`CF`、`TG`、`LA`、`NA`、`ST` 等不认）。内蒙古、北美 / 南美 / 拉美 / 中美不算地区。剩余、到期、官网、订阅、重置、流量、网址等明确的信息节点一律丢掉；「群」「教程」这类软词只在认不出地区时丢，开关是「过滤非地区节点」。倍率按数字判断（`0.5x`、`x2`、`2倍`、`倍率:0.5`）：小于 1 或写了免费 / 低倍算低倍，不小于 2 或写了高倍算高倍，两者互斥。重名节点、和生成的组同名的节点改成 `名字 (2)`。地区选择组默认选它的自动选择。WireGuard 端点也参与分组。出站的 `domain_strategy` 改写成 `domain_resolver`（服务器 `dns-cn`）。
